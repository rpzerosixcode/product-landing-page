# Roadmap — AUREX Product Landing Page Development

Development roadmap for implementing the AUREX Product Landing Page in Vue.js based on the finalized Figma design.

The goal is to transform the approved design into a responsive, accessible and functional product landing page while maintaining visual consistency with the original design and organizing the interface through reusable UI, layout and section components.

> **Release Note:** After all phases are completed and the project passes the final review, it will be released directly as **v1.0.0**, representing the first stable version.

> **Responsive Note:** The implementation should naturally consider Tablet layouts when necessary, adapting the interface between Desktop and Mobile without introducing unnecessary complexity.
